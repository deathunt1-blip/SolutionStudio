# Phase 1.2 · 完整技术方案工作台

版本：v0.4.0。原有本地数据、飞书连接、产品事实和去重记录继续保留。升级首次启动自动应用需求工作台与章节知识迁移；建议先备份整个 `data` 目录。

## 项目资料与需求

项目页面分为项目理解、客户需求、项目事实、工程数据、项目资料和方案。客户需求页可维护独立补充说明，项目理解中可直接回答待补充问题。可以上传或替换资料、删除单项输入及项目；SceneLab 报告也使用同一删除与替换流程。替换先成功解析新输入，再原子替换旧记录；解析失败保留原输入。删改输入后需重新核对项目理解，旧方案显示资料已变化，不会静默覆盖其快照。

补充说明作为独立记录保存，支持标题、正文、编辑与删除。模型处理失败时说明仍在，重试不会重复创建。客户要求保留来自文件和补充说明的证据，重复要求归并，不同数值保留候选，人工选择后再进入正文。可以手工增加要求、确认事实、修改项目画像，并直接回答待补充问题，或标为未知、不适用、按常规方案处理。

K3 按本项目全部可提取资料的语境提取要求、事实候选及画像；模型已审阅的资料不会再次被宽泛关键词规则污染。LED 刷新率、摄像机参数、光学设备参数和项目验收指标应分别审阅。人工决定保留，后续新增资料也保留来源和冲突关系。

项目资料与生成结果只供所属项目使用。删除与替换会检查生成任务状态；生成进行中不能覆盖其输入。删去报告后，当前工程数据和配图列表同步移除；已被旧方案正文或封面引用的图片按原来源保留，供旧方案继续导出，新方案不能重新选用这些图片。删除整个项目时一并清理。已有方案支持复制及删除。

## 深度知识整理

资料库的深度整理支持所选资料、当前筛选及全部资料。默认 Kimi K3，预算留空表示不设置人工金额上限；只发送明确选中的范围。

原文按真实标题层级保存为完整章节；短摘要、软标签、章节类型和写作蓝图另行保存，不替代原文。蓝图描述本章目的、推荐结构、通用技术逻辑、需要的项目事实及不可直接复用的项目内容。文档与章节可分别设置普通、优质、优先参考等级。

标签维度包括应用、对象、场景、技术主题、模块、产品、阶段、环境、约束及交付物。别名归并进入建议列表，人工接受后才修改词表；维度缺失时必须先选择。模型的置信度不足不等于事实已经确认。章节检索同时考虑章节类型、项目画像、关键词、产品及参考质量，并排除归档、重复从属资料和过期版本。

付费回复先保存在本地私有对象目录，键包含原文版本、完整请求及模型配置。相同请求可在解析规则修复后复用，缓存命中不重复累计费用。缓存不会因新版本或模型配置变化被错误套用。

## 章节成稿与技术图

先编辑方案目录，再生成正文。目录支持新增、删除、改名、层级、排序、每章配图方式及保存为自己的目录模板。编辑器支持 1–60 个章节条目，左侧目录和右侧辅助面板独立滚动，一级章节可折叠。

每章单独构建写作任务、项目事实、客户要求、已选产品权威参数及历史整段章节。概述不接收详细仿真统计、镜头参数和产品参数全文；部署、覆盖、精度等章节分别选择相关事实，完整快照仍用于独立校验。历史方案仅提供写作方式和技术逻辑，其客户、尺寸、数量、型号与指标不会因此成为当前项目事实。参考章节附带原适用对象和不可照搬内容，写作任务使用一套连贯结构。权威资料仍需匹配已选型号；标准条款不能直接证明产品已具备某种能力。正文不写内部字段、检索痕迹、来源文件名和待办清单；发现此类内容时自动重写一次，仍不合格则保留旧内容并显示失败原因。

校验还覆盖取消要求被旧记录重新带回、断言引用未列在汇总引用中、预测补全被写成真实实测、零误差同步、任意遮挡不影响性能等情况。项目特有的自然语言禁承诺仍需回到原文审阅，自动规则不能穷尽全部技术语义。

如果正文中的参数有正确资料支撑，但模型漏引了来源，可在章节参考资料中选择“补充章节依据”。该操作不调用模型、不改正文；服务器从当前有效资料版本重新读取依据，并检查所属项目、产品选型、权威级别和文档版本。历史方案或标准不会因此变成产品能力证明。后续生成技术图会保留这些人工补充的引用；重新生成正文则重新建立来源关系。

章节提纲由当前章节目标与已确认配置组织，历史蓝图的具体结构、算法和选型仅作为带来源的参考。系统不会把历史的开放/封闭双方案、分区标定、独立同步器或融合算法当作当前项目的默认决定。几何数值校验区分长、宽、高及净距，并完整比较区间两端；显示刷新率与相机帧率、3D 空间分辨率与系统定位精度分别核对，覆盖率按最近子句中的视点层级匹配。仅在明确文件格式语境中将 C3D 识别为格式名。

Mermaid 支持生成、编辑、预览和删除。标准目录 v4 默认规划系统架构图，已有目录版本保持原样；完成正文后，可用“生成计划技术图”一次处理尚未生成的计划图形。图形生成保留章节正文及其人工编辑保护。浏览器显示 SVG，导出时本地渲染为 PNG 并插入 Word。图中不能携带外链、脚本或外部图片。流程图依据与正文来源一起保存。配图也可以上传本项目 PNG/JPEG，或选择资料库原始 Office 文件中已有的图片，保留来源版本。AI 概念插画和上传 Word 后自动解析版式未在本版实现。

## 导出

每次导出先打开设置，可选择公司 Logo、标题、公司名称、品牌色、字号和页眉，并查看封面样式。点击导出时重新校验最新事实；新发现的问题留在弹窗中，不能沿用旧校验结果直接下载。内部工作语言和明确不当技术承诺会阻止导出；其它事实错误或未完成章节会列出提示，需要明确选择作为审阅稿导出。

内置“青瞳 · 简洁技术方案”主题使用 A4 白底、绿色标题与表格、一级章节另起一页，包含三级目录、章节编号、页眉页脚及页码字段。图表统一编号，标题与内容尽量同页，图宽适配正文区域。封面不带正文页眉。

DOCX 可编辑。Word 打开后应更新目录和页码字段；浏览器封面预览不代表 Word 的逐页实际排版。当前环境缺少文档技能要求的捆绑 LibreOffice，已验证 DOCX 包结构、内容及图像，但不能声称完成导出文档逐页视觉验收。实测范围见 [验证记录](PHASE_1_2_VALIDATION.md)。

## 模型、费用与数据

新需求提取、深度整理和方案生成默认 K3；方案推理强度默认 max，人工 Token 与金额限制默认关闭。模型技术窗口、超时、并发保护及用量记录仍生效。用户可以重新启用限制。费用是本应用按返回用量计算的估算，与共享账户余额无关。

源文件、回复缓存、真实回归样例和密钥仅保存在本机，不进入 Git 仓库。历史复建验收项目有明确标记；原文复核仅用于该样例，不冒充新客户确认，也不升级为全局权威参数。
