# Phase 0.2 智能整理验收

验收环境：Windows、本地 PGlite、Kimi 中国区 `kimi-k2.6`。真实资料和请求返回仅保留在本机被忽略的 `output/phase02/`，本文仅记录脱敏统计。验收于 2026-09-22 开始。

## 实现范围

- 原始文件名、解析标题、规范标题分开保存。新导入默认使用清理后的文件名；章节标题不再直接覆盖展示名称。迁移保留已有标题，优化通过建议确认后生效。
- 单份资料一次请求生成标题、摘要、分类和标签建议；相同值不重复列为修改项。人工标题、人工确认分类和标签默认保护。
- 资料库可选择 10 份、当前页、当前筛选结果或全部资料；支持选择整理字段、归档和新建知识分组。
- 建议页支持原值/建议值/依据对照、筛选、分页、逐项接受或拒绝、编辑后接受、只接受标题或标签、接受高置信度建议。
- 应用检查当前版本、当前值和人工锁，写入审计并更新检索。应用后可整批撤销；若存在后续编辑或版本变化，整次撤销返回冲突，不覆盖之后的修改。
- 相似资料通过 PostgreSQL 全文检索和标题、摘要、标签、目录信息召回。强参考限定为当前版本的人工确认资料；未确认 AI 结果最多是权重 0.3 的弱参考。权威级别与产品必须由当前文件自身证据支持。
- 整库分析每请求最多 50 张轻量卡片，生成知识分组、主题/实体别名、疑似版本和异常建议。明确确认后才创建分组或登记别名。

## 质量与范围边界

生成建议成功不代表分类准确率达标。原有人工分类保持不变，未进行新的完整人工标准答案评测；不能据此宣称 Phase 0.1 的分类错误已全部消除。模型置信度也不是经过校准的正确率。

原来泛化标题的正式展示需要用户接受对应建议后才改变。缺少当前文件证据的标题或产品建议被过滤；遇到扫描件或无法解析的资料，仍需先解决解析问题。

跨两个已注册主题的合并暂返回冲突，避免静默重写已有标签；本版可确认同一主题下无冲突的别名。实体别名登记不自动改写全部产品标签。疑似版本和异常仅供核对，不自动合并原文件。相似度使用词法检索，未启用 embedding、pgvector、复杂知识图谱或模型训练。
