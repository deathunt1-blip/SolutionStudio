本轮完整自动化测试通过 516 项，生产构建通过。真实成稿评审发现的问题已纳入回归测试，并完成最终全量复跑。依赖审计包含开发依赖，已验证零已知漏洞。

## 浏览器验收

- 25、40、60 章目录均能使用滚轮到达末项，目录滚动时主页面保持原位；选中末章有效。
- 一级标题展开/收起有效，25 项目录折叠后显示 21 项。
- 1440×1000 桌面布局中，目录与辅助栏独立滚动；700 像素宽度下导出设置改为单列，封面预览无横向溢出。
- Mermaid SVG 节点可见，代码编辑、渲染为 PNG 和导出嵌入通过测试。
- 在独立验收项目上传封面测试图片后，弹窗保持打开、预览更新；保存并重新打开后选择仍保留。
- 未完成章节列入导出提示；审阅稿确认默认不勾选，导出按钮保持禁用。
- 人工补充要求保存成功，项目理解随之要求重新确认。

以上来自同一 Chromium 内置浏览器，不代表分别运行了 Chrome 和 Edge。
